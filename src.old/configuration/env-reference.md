# Environment Variable Reference

This page collects the primary environment variables used by the NinjaPortal backend packages.

## Portal (`ninjaportal`)

- `APIGEE_PLATFORM` (`edge` | `apigeex`)

## Portal API (`portal-api`)

### Route / auth context

- `PORTAL_API_PREFIX`
- `PORTAL_API_ADMIN_PREFIX`
- `PORTAL_API_CONSUMER_MODEL`
- `PORTAL_API_ADMIN_MODEL`
- `PORTAL_API_CONSUMER_GUARD`
- `PORTAL_API_ADMIN_GUARD`

### Tokens

- `PORTAL_API_ACCESS_TTL`
- `PORTAL_API_REFRESH_TTL`
- `PORTAL_API_JWT_SECRET`

### Refresh token pruning

- `PORTAL_API_REFRESH_PRUNE_ENABLED`
- `PORTAL_API_REFRESH_PRUNE_QUEUE`
- `PORTAL_API_REFRESH_PRUNE_FREQUENCY` (`daily` | `hourly`)
- `PORTAL_API_REFRESH_PRUNE_TIME`

### Activity logging and RBAC

- `PORTAL_API_ACTIVITY_ENABLED`
- `PORTAL_API_RBAC_ENABLED`
- `PORTAL_API_RBAC_BYPASS_ROLES`
- `PORTAL_API_RBAC_ACCESS_ADMIN_PERMISSION`
- `PORTAL_API_RBAC_MANAGE_RBAC_PERMISSION`
- `PORTAL_API_RBAC_MANAGE_ADMINS_PERMISSION`
- `PORTAL_API_RBAC_VIEW_ACTIVITIES_PERMISSION`
- `PORTAL_API_USE_POLICIES`

## Portal MFA (`portal-mfa`)

### Global + actor toggles

- `PORTAL_MFA_ENABLED`
- `PORTAL_MFA_CONSUMER_ENABLED`
- `PORTAL_MFA_CONSUMER_REQUIRED`
- `PORTAL_MFA_CONSUMER_ALLOW_DISABLE`
- `PORTAL_MFA_CONSUMER_DEFAULT_DRIVER`
- `PORTAL_MFA_ADMIN_ENABLED`
- `PORTAL_MFA_ADMIN_REQUIRED`
- `PORTAL_MFA_ADMIN_ALLOW_DISABLE`
- `PORTAL_MFA_ADMIN_DEFAULT_DRIVER`

### Authenticator app (TOTP)

- `PORTAL_MFA_AUTHENTICATOR_ISSUER`
- `PORTAL_MFA_TOTP_DIGITS`
- `PORTAL_MFA_TOTP_PERIOD`
- `PORTAL_MFA_TOTP_WINDOW`
- `PORTAL_MFA_TOTP_SECRET_LENGTH`

### Email OTP

- `PORTAL_MFA_EMAIL_OTP_DIGITS`
- `PORTAL_MFA_EMAIL_OTP_TTL`
- `PORTAL_MFA_EMAIL_OTP_RESEND_COOLDOWN`
- `PORTAL_MFA_EMAIL_OTP_MAX_ATTEMPTS`
- `PORTAL_MFA_EMAIL_OTP_MAX_RESENDS`
- `PORTAL_MFA_EMAIL_MAILER`

### Challenge settings

- `PORTAL_MFA_CHALLENGE_TOKEN_LENGTH`
- `PORTAL_MFA_LOGIN_CHALLENGE_TTL`
- `PORTAL_MFA_CHALLENGE_PRUNE_AFTER_DAYS`
- `PORTAL_MFA_ROUTES_ENABLED`

## Host app / Laravel (commonly required)

These are not NinjaPortal-specific but are operationally important:

- `APP_URL`
- `APP_KEY`
- DB connection variables
- mailer variables (`MAIL_*`)
- queue/cache drivers
- JWT/library-specific settings (if used outside `portal-api` overrides)
