# NinjaPortal Documentation

NinjaPortal is a modular developer portal platform for API providers, designed to work with Apigee and to be extended package-by-package.

This documentation is the primary onboarding path for engineers who need to:

- install and run the platform
- understand the architecture and package boundaries
- customize models, services, policies, and API behavior
- integrate with Apigee (Edge / Apigee X)
- extend authentication and authorization
- operate, document, and ship the platform safely

## What is in scope

This docs site focuses on the two core packages that power the solution:

- `ninjaportal/portal` (core domain package)
- `ninjaportal/portal-api` (REST API package)

It also documents optional extensions (such as `ninjaportal/portal-mfa`) in the authentication and reference sections.
