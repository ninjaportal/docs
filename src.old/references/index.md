# References

This section collects the detailed reference material across NinjaPortal packages.

Use it when you need precise implementation details, event names, schema fields, or package-specific config docs.

## How to use this section

If you are looking for:

- **core package capabilities and APIs** → start with the package references (`portal`, `portal-api`)
- **exact table fields and relationships** → use the schema reference
- **event names / payloads** → use the events catalog
- **built-in listeners/observers/subscribers** → use the listeners & observers page
- **endpoint-level REST reference** → use the Scribe docs page
- **configuration keys** → use the package config references and env reference
